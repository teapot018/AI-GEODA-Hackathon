# 단독 실행 데모 (`index.html`)

서버 없이 **파일 하나로 도는** FC 스쿼드 콘솔입니다. 더블클릭해서 브라우저로 열면 바로 동작합니다.

```bash
open demo/index.html          # macOS
xdg-open demo/index.html      # Linux
start demo\index.html         # Windows
```

## `fc-squad-maker/` 와 무엇이 다른가

|  | `demo/index.html` | `fc-squad-maker/` (Next.js) |
| --- | --- | --- |
| 실행 | 파일 열기 | `npm install && npm run dev` |
| 데이터 | 결정적 샘플 데이터 (내장) | 넥슨 Open API 실호출 (`NX_API_KEY` 필요) |
| API 프록시 | 없음 (서버가 없음) | `/api/*` Route Handler |
| 용도 | 화면·로직을 바로 보여주기 | 실제 서비스 |

두 판은 **같은 로직**을 공유합니다 — 한글 초성 검색, 시드 난수 가중 추첨,
BP 가치·강화 곡선 모델, 팀컬러·포지션 적합도 평가. 선수 시드 64명은
`fc-squad-maker/src/lib/players/dataset.ts` 에서 그대로 추출한 값입니다.

## 담긴 기능

- **스쿼드 메이커** — 초성 검색(`ㅅㅎㅁ` → 손흥민), 6종 포메이션, 드래그 배치와
  슬롯 교체, 자리별 자동 채우기, 팀컬러·적합도 평가, 강화 +1~+10 곡선(로그 축).
  구성은 `localStorage` 에 저장됩니다.
- **구단주 조회** — 닉네임 → OUID → 레벨·최고 등급·매치 8경기(펼치면 출전 명단
  11인)·이적시장 거래 내역. 같은 닉네임은 언제나 같은 결과가 나옵니다.
- **모의 상자 개봉** — 확률·기대값 사전 공개, 가중 추첨, 천장, 개봉 연출,
  세션 회수율 집계. 결과에 시드가 남아 같은 판을 다시 뽑을 수 있습니다.

## 한계 — 무엇이 실데이터가 아닌가

이 페이지에는 서버가 없어 넥슨 Open API 를 **호출하지 않습니다**(브라우저에서
직접 부르면 CORS 로 막히고, API 키를 숨길 곳도 없습니다). 구단주 정보와 매치
기록은 닉네임을 시드로 만든 샘플입니다.

능력치·오버롤·BP 가치·강화 상승폭·팀컬러는 **공개 API 에 없는 항목**이라 양쪽 판
모두 자체 추정 모델을 씁니다. 상자 확률과 가격도 이 프로젝트가 정한 샘플 값이며,
실제 확률은 게임 내 ‘확률 공개’ 페이지 공시를 따릅니다.
