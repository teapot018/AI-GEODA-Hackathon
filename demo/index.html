모의 상자 개봉

—

넥슨 FC 온라인을 소재로 한 비공식 팬 프로젝트입니다. 이 페이지는 서버 없이 브라우저에서만 도는 판이라 넥슨 Open API 를 직접 호출하지 않고, 저장소와 동일한 결정적 샘플 데이터 위에서 같은 로직을 돌립니다. 능력치·오버롤·BP 가치·팀컬러는 공개 API 에 없는 항목이라 자체 추정 모델이고(게임에 뜨는 값이 아닙니다), 상자 이름·가격·확률도 이 프로젝트가 만든 모의 값입니다. 강화 단계별 오버롤 상승(+1~+13)만 넥슨 공식 값입니다. 강화 팀컬러(물결) 단계표는 커뮤니티 정리에서 가져온 미검증 값이라 종합 점수에 넣지 않습니다.
